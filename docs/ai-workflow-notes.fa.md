# یادداشت داخلی — اثر هوش مصنوعی و چند ایجنت بر هزینه

این سند برای تصمیم خود توسعه‌دهنده است و داخل بسته پیش‌نمایش مشتری قرار ندارد.

## پاسخ عملی

بله، استفاده مناسب از AI می‌تواند زمان تولید و اصلاح کد و بخشی از زمان انسانی را کم کند. خرید حساب یا افزایش تعداد ایجنت، به‌تنهایی کاهش هزینه یا زمان را تضمین نمی‌کند. برای این پروژه هنوز پایلوت توسعه Angular و .NET و اندازه‌گیری بهره‌وری نداریم؛ درصد صرفه‌جویی قطعی قابل دفاع نیست.

برآورد ۲۰۰–۳۱۰ ساعت یک تخمین کار پروژه است، نه نتیجه مقایسه کنترل‌شده توسعه با و بدون AI. بنابراین نباید آن را یک بار به‌خاطر AI و یک بار به‌خاطر پایه آماده، بدون بررسی دوباره کم کرد.

## سه عدد متفاوت

- زمان تقویمی: چند روز یا هفته تا تحویل.
- نفرساعت انسانی: طراحی، هدایت، بررسی، یکپارچه‌سازی، آزمون و عملیات انجام‌شده توسط فرد.
- مصرف ابزار: اشتراک، اعتبار، API یا مصرف مدل.

ساعت‌های ایجنت‌ها به نفرساعت انسانی اضافه نمی‌شوند. اجرای سه ایجنت هم‌زمان نیز لزوماً سه برابر سریع‌تر نیست. کم‌شدن زمان تقویمی ممکن است با افزایش مصرف مدل یا زمان هماهنگی همراه شود.

## یک مثال فرضی، نه وعده

فرض کنیم یک کار ۲۰۰ ساعت انسانی برآورد شده باشد: ۸۰ ساعت تصمیم، بررسی، آزمون و تحویل؛ ۱۲۰ ساعت تولید و اصلاح کد. اگر AI بخش دوم را نصف کند، عدد کل به ۱۴۰ ساعت می‌رسد. اگر ۱۵ ساعت هماهنگی و اصلاح خروجی اضافه شود، نتیجه ۱۵۵ ساعت است. با نرخ فرضی ۵۰۰ هزار تومان، صرفه‌جویی ناخالص دستمزد ۲۲٫۵ میلیون تومان می‌شود؛ هزینه افزوده ابزار از آن کسر می‌شود. این فرض برای پروژه اندازه‌گیری نشده و در قرارداد تضمین نمی‌شود.

## تقسیم کار پیشنهادی برای مرحله توسعه

بعد از تثبیت قرارداد API و مرز فایل‌ها، دو تا سه کار مستقل کافی است:

- رابط مشتری یا پنل مدیریت.
- بررسی API و آزمون‌های قیمت/سفارش.
- بازبینی مستقل پرداخت، دسترسی فایل یا تست مرورگر.

تصمیم‌های معماری و ادغام نهایی یک مسئول داشته باشند. چند ایجنت هم‌زمان روی یک فایل یا مدل داده مشترک، بدون مالکیت مشخص، هزینه هماهنگی ایجاد می‌کند. بخش‌های وابسته مانند تغییر فرمول و تست پذیرش آن باید هماهنگ و مرحله‌ای انجام شوند.

## پیش از خرید

1. یک پایلوت فنی محدود، مثلاً فرم بنر Angular و یک API با قاعده آزمایشی مشخص، اجرا شود؛ نه فروشگاه کامل.
2. حدود ۱۲–۲۰ ساعت انسانی برای برنامه‌ریزی این بررسی کنار گذاشته شود؛ زمان واقعی ثبت شود. کار قابل استفاده آن در فاز بعد دوباره محاسبه نشود.
3. مصرف ابزار، زمان هدایت، بازکاری، بررسی و خروجی قابل استفاده ثبت شوند.
4. اگر سهمیه واقعاً مانع کار بود، ارتقا یا اعتبار با سقف مصرف مشخص انتخاب شود.
5. سپس برآورد باقی‌مانده بر اساس اندازه‌گیری اصلاح شود.

پیشنهاد خرید پیشاپیش چند حساب یا بالاترین پلن ندارم. هزینه ابزار بهتر است روی حساب فرد اجراکننده، یا صندلی اختصاصی او در محیط کاری مشتری، با دسترسی و پرداخت روشن تأمین شود. حساب شخصی احسان و رمز آن بین افراد به اشتراک گذاشته نشود.

## اطلاعات رسمی بررسی‌شده در ۲۰۲۶/۱۱/۱۵

- صفحه رسمی قیمت: Plus ماهانه ۲۰ دلار؛ Pro از ۱۰۰ دلار با گزینه‌های ۱۰۰، ۲۰۰ و ۵۰۰ دلار. مبلغ خرید واقعی، مالیات و روش پرداخت باید در زمان خرید بررسی شود. https://learn.chatgpt.com/docs/pricing
- اشتراک و استفاده API مدل‌های حسابداری متفاوت دارند؛ قیمت توکن API را نباید برای تخمین کارهای مشمول اشتراک استفاده کرد. اعتبار احتمالی API در حساب باید جدا بررسی شود. همان منبع قیمت.
- مستندات رسمی می‌گویند اجرای subagent به دلیل کار مستقل مدل و ابزار، معمولاً توکن بیشتری از اجرای مشابه تک‌ایجنت مصرف می‌کند. کارهای مستقل می‌توانند سریع‌تر پیش بروند؛ نوشتن موازی کد، تعارض و سربار هماهنگی دارد. https://learn.chatgpt.com/docs/agent-configuration/subagents
- حساب شخصی برای استفاده همان فرد است. https://help.openai.com/en/articles/10471989-openai-account-sharing-policy
- مصرف به مدل، پیچیدگی، زمینه، ابزار و سرعت وابسته است و باید در صفحه مصرف همان حساب بررسی شود. https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan

این یادداشت درباره امکانات موجود این جلسه، تعداد ایجنت مجاز در پلن احسان یا سهمیه دقیق او ادعایی نمی‌کند. هنوز در این مرحله ایجنتی برای توسعه موازی اجرا نشده است.
